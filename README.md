# Concrete Village Mod

Enhance your Minecraft world with concrete villages and more villagers.

## Features

- Adds concrete blocks to the game
- Introduces concrete villagers with unique spawn eggs

## Requirements

- Minecraft 1.21.4
- Fabric Loader 0.14.0 or later

## Installation

1. Download the mod from the [releases page](https://github.com/EnderDevelopment/concrete-village-mod/releases)
2. Place the mod in your `mods` folder
3. Launch Minecraft with Fabric

## Usage

### Concrete Block

- Crafted using gravel and sand
- Used to build concrete buildings and structures

### Concrete Villager

- Spawned using a concrete villager spawn egg
- Can be traded with for concrete blocks and other items

## Configuration

The mod does not have any configuration files. All settings are hardcoded in the mod.
